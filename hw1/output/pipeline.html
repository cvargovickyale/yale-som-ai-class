P2 — Read receipts

Reads: receipt PDFs. Writes: receipts.json, with vendor, date, description, amount, category, and source file. Luna extracts facts; missing values are not invented.

P3 — Read bank statement

Reads: January bank PDF. Writes: bank_transactions.json, classifying each line as business/personal, credit/debit, and accounting label. Luna interprets statement lines.

P4 — Read credit card

Reads: January credit-card PDF. Writes: credit_card_transactions.json. Luna extracts charges and preliminary categories; personal rows keep a null category.

P5 — Reconcile

Reads: the three transaction JSON files plus relevant emails, memos, and supporting PDFs. Writes: reconciliation_log.json. Luna matches duplicates, separates mixed amounts, and explains the resolution.

P6 — Judgement calls

Reads: reconciliation decisions. Writes: judgment_calls.json containing the three uncertain calls, evidence, inclusion decision, amount used, and confidence. This is a review artifact rather than a Python script.

P7 — Income statement

Reads: reconciliation_log.json. Writes: income_statement_jan2026.json. Plain Python includes every yes row, separates revenue and expenses, and calculates net income without hardcoded amounts.

P8 — Webpage

Reads: the income statement, reconciliation log, and judgement-call JSON files. Writes: income_statement.html, a one-page human-readable summary with totals, excluded rows, and judgment calls.

Important: Luna is used for extraction and interpretation in P2–P5. P7 and P8 are deterministic Python transformations, so their displayed totals come from the saved JSON artifacts.
